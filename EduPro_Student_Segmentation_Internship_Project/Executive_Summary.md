# Executive Summary

## EduPro Personalization Engine
**Objective:** Understand learner behavior, segment learners and provide personalized course recommendations.

### Key outputs
- Learner profile explorer
- K-Means segment dashboard
- Hierarchical clustering validation
- Cluster-aware recommendations
- Category/level filtering
- Course and segment analytics
- Offline Precision@5 proxy
- Elbow and Silhouette analysis

### Decision value
The system helps EduPro move from generic recommendations toward adaptive learner journeys. Segments can be used by marketing, academic teams and product teams to tailor course discovery and engagement campaigns.

### Data limitation
The current workbook does not contain completion, click-through, retention or recommendation-exposure fields. Engagement Lift is therefore not claimed as a measured result. These events should be collected before production A/B testing.
